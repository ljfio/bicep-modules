# dns

Bicep function library that maps Azure resource types to the Private DNS
zone names Azure requires for Private Endpoints, so consumers stop hand-writing
zone lists.

- Zone names come from the
  [Microsoft Learn private endpoint DNS configuration](https://learn.microsoft.com/azure/private-link/private-endpoint-dns)
  appendix. `scripts/generate_dns.py` cross-checks every curated zone against
  that page when it can reach it, and falls back to the curated mapping when
  it cannot; the emitted files are identical either way.
- Type keys match the naming module's resource type keys
  (`storage_account`, `key_vault_vault`, ...).

Repository layout: `dns.bicep` and this README are hand-written; `zones.bicep`
(zone keys and zone map) and `zones.md` (the zone catalogue) are generated by
`scripts/generate_dns.py`.

## Usage

```bicep
import * as dns from 'br/ljfio:dns:0.3.0'

resource privateDnsZone 'Microsoft.Network/privateDnsZones@2020-06-01' = {
  name: dns.privateDnsZone('storage_account_blob') // privatelink.blob.core.windows.net
  location: 'global'
}
```

A resource type that requires several zones resolves them all at once:

```bicep
var storageZones = dns.privateDnsZones('storage_account')
// -> [
//   'privatelink.blob.core.windows.net'
//   'privatelink.dfs.core.windows.net'
//   'privatelink.file.core.windows.net'
//   'privatelink.queue.core.windows.net'
//   'privatelink.table.core.windows.net'
// ]

resource zone 'Microsoft.Network/privateDnsZones@2020-06-01' = [for z in storageZones: {
  name: z
  location: 'global'
}]
```

## Exported types

| Type | Description |
|---|---|
| `privateDnsZoneKey` | Union of all supported zone keys: naming-style resource type keys, with a `_<group>` suffix for resource types that require several zones (`storage_account_blob`); a single-zone type is its own key (`key_vault_vault`). |

## Functions

| Function | Description |
|---|---|
| `privateDnsZone(key privateDnsZoneKey)` | The Private DNS zone name Azure requires for a resource type group (`storage_account_blob` -> `privatelink.blob.core.windows.net`). Unknown keys are rejected at build time. |
| `privateDnsZones(resourceType string)` | All Private DNS zones a resource type requires (`storage_account` -> the blob, dfs, file, queue and table zones); an empty array for type keys outside the catalogue. |
